
```bash

```

## 制作メモ

・画像やJSについて<br>
既存の資材をなるべく利用する様に作成する事として実施しました。

・ディレクトリについて<br>
staticのディレクトリに配置するよりも、纏めた方がより実践的と思い下記ディレクトリにファイルを新規作成しました。
```
/_src/js/meteo.js
/_src/sass/layout/layout.scss
```

・ファビコンについて<br>
icoファイルが無いので設定しませんでした。

・モバイル表示について<br>
レスポンシブ、メディアクエリにより768px以下をモバイル表示と設定しました。

・気温の前日比について<br>
デザインの数値を見た所、四捨五入か繰り上げ繰り下げが不明だったため、分かりやすい様に小数2位の表示としました。

・降水確率について<br>
デザインでは、0％と--がありました。APIで得たデータをそのまま利用する事として、0で統一としました。
